NOX01 Mobile helps you use Android with an AI agent. Describe a task and a supported agent can read the screen, tap, scroll, enter text and open apps through Android's accessibility features.

Available agents include Claude Code, Codex, OpenCode, Antigravity and Grok. Account requirements vary by service. Android 11+ and a 64-bit device are required.

Features include:
• Floating assistant bubble with expressive pixel-art character
• Chats, voice requests and optional text-to-speech
• App control with permission and approval settings
• Notification rules and scheduled tasks
• Optional background browser, sub-agents and Linux development tools
• Local MCP phone tools and optional private-model connections
• Tactical Neu-Dark theme, adjustable colors and fonts
• Estonian interface and documentation

NOX01 is independently developed open-source software. It is not an official app of Anthropic, OpenAI, Google or xAI. What information reaches an AI service depends on your selected model and task. Use approval controls for sensitive actions.
